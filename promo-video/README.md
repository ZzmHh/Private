# 凡梦AI 宣传动画（横屏 · 60 秒）

Remotion 代码渲染 **1920×1080 横屏** 产品宣传片，使用官方 Logo，含完整产品介绍文案。

## 成片结构（约 57 秒）

| 时段 | 内容 |
|------|------|
| 开场 | Logo + 产品定位 + 支持平台 |
| 痛点 | 4 大跨境卖家难题 |
| 概览 | 6 大模块 + 5 Agent 一键运营 |
| 模块详解 ×6 | 每个 Agent：功能说明 + 能力点 + 输出示例 |
| 插件 | TikTok Shop Chrome 插件演示 |
| 上手 | 三步流程 |
| 定价 | 四档套餐摘要 |
| 结尾 | Logo + CTA |

## 命令

```bash
cd promo-video
npm install
npm run preview          # 预览
npm run render           # 导出横屏 MP4
```

输出：`out/fanmeng-ai-promo-landscape.mp4`

网站引用：`public/media/fanmeng-ai-promo-landscape.mp4`

Logo 文件：`promo-video/public/fanmeng-ai-logo.png`
