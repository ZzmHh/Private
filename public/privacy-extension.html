凡梦AI · TikTok Shop 浏览器助手 · 隐私说明

最后更新：2026-05-20 · 适用于 Chrome / Edge 扩展「凡梦AI · TikTok Shop 助手」

我们收集什么

  • 凡梦账号登录信息：邮箱登录后获得的令牌，仅用于调用凡梦服务端 API。
  • TikTok 卖家中心页面内容：仅在您点击「同步本页」、客服话术或诊断功能时，读取当前浏览器标签页中与店铺相关的文本/表格样本，并上传到您的凡梦账号。
  • 本地设置：店铺绑定名称、回复模板、自动化开关等，保存在浏览器本地存储。

我们不做什么

  • 不读取 TikTok 登录密码；不代替您在 TikTok 后台点击「发送消息」。
  • 不向第三方出售数据。
  • 除凡梦 API 与您主动同步外，不上传无关网站内容。

权限说明

扩展需访问 TikTok 卖家中心域名，以便注入辅助面板并读取您当前查看的页面。需访问凡梦 API 域名以便登录与 AI 功能。

数据存储与删除

页面快照与 AI 结果存储在凡梦 SaaS 服务端，与您的账号关联。您可在网站内删除任务历史；卸载扩展不会删除服务端数据，如需删除账号数据请联系凡梦支持。

联系我们

如有隐私问题，请通过凡梦网站注册邮箱或工单渠道联系运营方。
