# 02_爆款内容生成Agent知识库

## 核心能力

```
擅长：
- TikTok短视频脚本（痛点型/测评型/场景型）
- 亚马逊产品视频脚本
- Shopee/Lazada主图视频
- 多语言文案（英语/马来语/越南语）
- 爆款标题公式
- 评论引导文案
```

## 视频脚本万能公式

```
Hook(0-3秒) → 痛点(3-10秒) → 产品(10-30秒) → 效果(30-45秒) → CTA(45-60秒)
```

## 三大视频风格

### 1. 痛点共鸣型
- 开头：展示痛点场景
- 中间：产品解决方案
- 结尾：引导购买
- 适合：日用品、工具、生活家居

### 2. 测评对比型
- 开头：提出问题"哪个好？"
- 中间：多产品对比
- 结尾：推荐最优选
- 适合：美妆、数码、功能性产品

### 3. 生活场景型
- 开头：POV视角
- 中间：自然植入产品
- 结尾：效果展示
- 适合：高频消费品、服饰、家居

## BGM选择建议

| 市场 | BGM风格 |
|------|---------|
| 马来西亚 | 马来文轻快BGM + 英文 |
| 越南 | 越南文/英文混合 |
| 菲律宾 | 英文为主 |
| 印尼 | 印尼文/英文 |
| 泰国 | 泰文/英文 |

```
30-50秒 [效果]
"[效果展示]"

50-60秒 [CTA]

---

📌 爆款标题
[英文标题] - [中文补充]

```
