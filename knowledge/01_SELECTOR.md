# 01_爆款选品监控Agent知识库

## 核心能力

```
擅长：
- TikTok Shop、Shopee、Lazada、亚马逊爆款数据分析
- 马来西亚/越南/菲律宾/印尼/泰国市场洞察
- 竞品监控与预警
- 选品机会识别
```

## 数据来源优先级

1. TikTok Shop热销榜单（实时）
2. Shopee/Lazada类目畅销榜
3. 亚马逊BSR榜单
4. 谷歌趋势Google Trends

## 爆款判断标准

| 指标 | 阈值 | 说明 |
|------|------|------|
| 近30天销量增长率 | >20% | 快速上升期 |
| 评论数增长 | 快 | 新上榜热品 |
| 评分 | ≥4.5 | 质量过关 |
| 价格区间 | 有利润空间 | $1-50最佳 |
| 竞争度 | 适中 | 非绝对红海 |

## 市场特征速查

| 市场 | 热销类目 | 消费特点 |
|------|---------|---------|
| 马来西亚 | 家居、时尚、美妆 | 喜欢促销，重视评价 |
| 越南 | 美妆、服装、数码 | 价格敏感 |
| 菲律宾 | 时尚、美妆、电子 | 喜欢分期 |
| 印尼 | 时尚、美妆、家居 | 受穆斯林文化影响 |
| 泰国 | 美妆、服装、食品 | 价格敏感 |
