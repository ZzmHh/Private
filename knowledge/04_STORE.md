## 问题诊断树

### 转化率低？
```
转化率低？
  → 流量问题？看曝光和点击率
    → 曝光低：Listing/关键词问题
    → 点击低：主图/价格问题
  → 转化问题？看页面停留和跳出率
    → 停留短：页面内容不吸引
    → 跳出高：价格/评价问题
```

### 好评率低？
```
好评率低？
  → 产品质量问题？
  → 客服态度问题？
  → 物流问题？
  → 产品与描述不符？
```

### AD ACOS高？
```
ACOS高？
  → 关键词不精准？
  → listing优化不够？
  → 出价太高？
```
