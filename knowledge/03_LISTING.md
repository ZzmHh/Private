# 03_Listing转化优化Agent知识库

## 核心能力

```
擅长：
- 亚马逊/Shopee/Lazada/TikTok Shop Listing优化
- 主图/副图设计建议
- 五点描述（Bullet Points）
- 产品描述（Description）
- 关键词埋入
- A+内容优化
- 评分管理
```

## 亚马逊Listing公式

### Title公式
```
品牌 + 核心关键词 + 特性 + 规格 + 使用场景
```
例：JOYES Home Non-Stick Frying Pan, 26cm, Ceramic Coating, Oven Safe, For Kitchen

### 五点描述公式

1. **产品亮点**（最强卖点）
2. **解决问题**（针对痛点）
3. **场景适用**（谁适合用）
4. **规格参数**（具体数据）
5. **服务保障**（售后/发货）

## 各平台特点

| 平台 | Title要求 | 特点 |
|------|----------|------|
| 亚马逊 | 250字符内 | 严格，关键词要精准 |
| Shopee | 120字符内 | 突出促销信息 |
| Lazada | 120字符内 | 重视评价和销量 |
| TikTok Shop | 200字符内 | 冲动消费导向，突出性价比 |

## 评分维护

- 好评率目标：4.5星以上
- 差评处理：24小时内回复
- 索评时机：物流确认后7天内轻催评
