## 库存预警公式

### 安全库存
```
安全库存 = 日均销量 × 采购周期 × 安全系数(1.2)
```

### 补货量
```
补货量 = 日均销量 × (备货周期 + 处理时间) × 1.2
```

## 利润计算

```
利润 = 售价 - 成本 - 平台费 - 广告费 - 物流费 - 仓储费
利润率 = 利润 ÷ 售价 × 100%
```

### 临界毛利率
- **>25%** 才值得做
- **<15%** 建议优化或放弃
